# AI Usage

## 1. Purpose

AI assistance was used during the development of the Grade Management System as a support tool for learning, implementation guidance, debugging, code review, and documentation.

The final implementation was reviewed, integrated, and tested manually.

---

## 2. Areas Where AI Was Used

### Architecture and Project Structure

AI assistance was used to understand and plan:

* Backend and frontend separation
* FastAPI application structure
* Service-layer organization
* Validation-layer organization
* Calculation-layer organization
* Streamlit view and component organization
* Frontend API client structure
* Database layer organization

The final structure was reviewed and adapted according to the assignment requirements.

---

### Python and FastAPI Learning

AI assistance was used to explain and understand concepts such as:

* FastAPI routes
* REST APIs
* `Depends`
* SQLAlchemy sessions
* Pydantic models
* Request and response schemas
* Pagination
* Python decorators
* Database transactions
* `model_dump()`
* Dependency injection

These explanations were used to improve understanding before implementing the corresponding functionality.

---

### Backend Development

AI assistance was used for implementation guidance and code review related to:

* Student APIs
* Course APIs
* Semester APIs
* Assessment APIs
* Enrollment APIs
* Grade APIs
* Excel upload processing
* Student performance APIs
* Service-layer functions
* Validation functions
* Calculation functions

The suggested implementation was reviewed and integrated manually.

---

### Calculation Logic

AI assistance was used to understand and implement the required academic calculations:

* Course percentage
* Grade points
* Semester GPA
* CGPA
* Percentile
* GPA history
* Projected GPA

The calculation logic was checked against the assignment requirements and expected examples.

---

### Debugging

AI assistance was used while troubleshooting development issues including:

* Python import errors
* FastAPI startup problems
* Uvicorn execution
* SQLAlchemy and MySQL connection issues
* API routing issues
* Frontend-to-backend communication
* Streamlit UI issues
* Validation errors
* Excel upload issues

Issues were checked locally and fixes were tested before being integrated.

---

## 3. Verification and Review

AI-generated suggestions were not treated as automatically correct.

The implementation process involved:

1. Understanding the suggested approach.
2. Reviewing the code and logic.
3. Integrating the required changes.
4. Running the application locally.
5. Testing the functionality.
6. Debugging issues where required.
7. Making final implementation decisions based on the project requirements.

---

## 4. Developer Responsibility

The developer reviewed and integrated the final implementation.

AI was used as an assistance and learning tool rather than as an independent coding agent.

The final source code, database design, application behavior, and project decisions were reviewed by the developer.
